S1. Reproducibility and software

All analyses were conducted in R. Meta-analytic models were fitted using metafor, and score-based sign-flipping inference was performed using flipmeta. Random-number seeds were fixed for all simulation and resampling procedures.

The source code used to generate the simulations, empirical application, figures, and tables is available in the accompanying repository. The manuscript and supplementary materials were generated directly from Quarto source files.

S2. Computational comparison with permutation testing

The main manuscript notes that score sign flipping avoids repeated refitting of the complete meta-regression model. We illustrate the practical computational difference using a mixed-effects meta-regression with 100 independent studies and three predictors.

Both procedures used 1,000 resampling transformations. The benchmark is intended only as an illustration; computation times depend on the model, hardware, software versions, and number of resampling transformations. The timing results are summarized in Table 1.

In this example, metafor::permutest() required approximately 10.7 seconds, compared with 0.12 seconds for flipmeta (see Table 1).

S3. Additional simulation results

This section presents full condition-level empirical results from the simulation study evaluating specification-level inference. The interactive tables allow filtering across simulation conditions, including the number of studies (\(k\)), study sample size (\(n\)), baseline heterogeneity (\(\tau^2\)), unobserved confounder correlation (\(\zeta\)), moderator correlation (\(r_{XZ}\)), and regression coefficients (\(\beta_0, \beta_X, \beta_Z\)).

Five inferential procedures are evaluated: - mKH: Modified Knapp–Hartung adjustment - KH: Knapp–Hartung adjustment - RVE: Robust Variance Estimation with CR2 adjustment and Satterthwaite degrees of freedom - flipmeta: Score-based sign-flipping inference - Wald: Standard Wald \(z\)-test

Power

Empirical power under \(\beta_X = 0.2\) across simulated conditions. Green shading highlights higher power values (scale from 0 to 1).

Type I error

Empirical Type I error rates under \(\beta_X = 0\) across simulated conditions at nominal \(\alpha = 0.05\). Red shading highlights inflated Type I error rates exceeding 0.05.

S4. CBT depression specification curve

The specification curve (Figure 1) displays the complete set of unique analyses, ordered by their pooled effect estimate. “Non-discriminating” indicates that multiple nominal levels of a decision produced the same final analysis after conditioning on the other decisions.
